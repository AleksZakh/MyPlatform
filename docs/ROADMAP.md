# План развития Space

1. Права: назначения сотрудникам, отделам, группам AD и внутренним группам Space; проверка на реальном пользователе.
2. Проверка полноты аудита: выдача/отзыв прав, изменение состава групп, сопоставление и перевод сотрудников.
3. Единый журнал событий AUTH / DATA / ACCESS / SECURITY / ADMIN / SYSTEM и экран поиска.
4. Ограниченное делегирование руководителям подразделений.
5. Переиспользуемые роли.
6. Карточка отдела и формируемая страница отдела: сведения, ресурсы, службы и сервисы. Каталог страницы использует постоянный ID отдела и существующие проверки прав. Наличие ресурса на странице не выдаёт доступ само по себе.

Карточка и страница отдела согласованы как будущий этап, без реализации в этом пакете. Файловая подсистема и диагностика Kerberos остаются отложенными.
