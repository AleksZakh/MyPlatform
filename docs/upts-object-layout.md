# УПТС — широкая форма объекта и компактная таблица

Пакет Space-UPTS-object-layout-20261106 устанавливается поверх
Space-UPTS-work-stages-20261105.

Карточка объекта использует ширину до 1120 px (вместо 740 px), с отступами
по 14 px слева и справа. Фиксированная высота и внутренняя прокрутка сохранены.
Широкий режим включается отдельным свойством Modal только для формы объекта.

Характеристики размещены в две равные колонки. На экранах до 640 px используется
одна колонка. Повторяемые правообладатели и ВРИ сохраняют свои группы; у КУВД
номер и дата идут рядом, кнопка добавления остаётся под группой записей.

Таблица этапов оформлена по реестру договоров диагностов: шрифт 13 px,
серый заголовок, горизонтальные разделители, голубые подсветка и выделение.
Уменьшены вертикальные отступы ячеек, высота ввода этапа — 24 px.
Длинные названия могут переноситься, чтобы не обрезать содержание.
Для тёмной темы используются графитовые фон и голубое выделение.

«Этап для выбранных» — выпадающий список 1…N, где N — количество этапов работ.
При изменении N список обновляется. Если выбранный массовый номер выходит
за новый диапазон, в этом поле выбирается 1; назначения самих работ сохраняются
и при необходимости требуют переназначения, как в предыдущем обновлении.

Серверные API, данные и поля карточки не изменены. Миграции и новые зависимости
не нужны. Проверены TypeScript, компиляция Vue, существующие DOM-сценарии назначения
этапов и сохранения формы, применение установщика и защита от конфликтов.
Полная production-сборка и визуальная проверка в браузере целевого сервера
не выполнялись.
