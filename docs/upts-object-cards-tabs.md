# УПТС: вкладки и компактная карточка объекта

Обновление Space-UPTS-object-cards-tabs-20261105. База: Space-UPTS-objects-matrix-20261105.

## Форма объекта

Две вкладки: «Характеристика объекта» и «Работы с объектом». Прямоугольные вкладки
с иконками оформлены по образцу лаборатории: светлое выделение активной вкладки,
в тёмной теме — графитовый фон и голубой акцент. Поддерживаются клавиши стрелок,
Home/End и сохранение черновика при переключении.

Характеристики следуют порядку первого скриншота: объект (автомобильная дорога),
этап, правообладатели, область, тип сделки, исходный кадастровый номер и площадь,
вид права, ВРИ, тип объекта, тип учёта, условный номер, номер и дата КУВД.
Добавлены согласованные отдельные номер и дата договора. Правообладатели, ВРИ и
записи КУВД повторяемые. Справочники, значения которых заказчик ещё не передал,
допускают ручной ввод; дороги и этапы подсказываются по доступным записям.

Из формы убраны отдельное наименование, куратор, инженер, срок, настройка видимости,
старый контрагент/дата и технические пояснения. Новый объект по-прежнему получает
видимость «Всем сотрудникам управления»; доступ затем настраивается существующими
кнопками рабочей области. Название новой записи формируется по кадастровому номеру,
при его отсутствии — по условному. Название прежней записи не переписывается.

Во вкладке работ — вид работ, шаблон и список входящих работ с ролью и результатом;
для «Иного» — ручной ввод. При редактировании показаны существующие работы.
Добавление отдельных работ остаётся доступно из компактной карточки и панели объекта.

## Компактная карточка

В обзоре и списке объектов большой блок реквизитов заменён карточкой шириной до 250 px.
Показываются кадастровый номер (либо условный номер), дорога, этап, номер и дата договора.
Сумма не выводится по уточнению пользователя. Цвет объекта сохранён; фон карточки
учитывает тему. Кнопки открывают работы, документы, редактирование и добавление работы.
Иконки телефона/почты без подключённого действия не добавлялись.

## Форма работы

Упрощение касается только УПТС. Оставлены название, исполнитель, состояние, справочные
вид работ/ответственная роль/ожидаемый результат. Привязка к объекту остаётся в заголовке;
для новой задачи без привязки сохраняется возможность выбрать объект.
Скрыты общие поля проектов, приоритет, тип задачи, описание, даты, препятствие,
участники и обсуждение. Их ранее сохранённые значения не очищаются.
Обычные задачи Space сохраняют прежнюю полную форму.

## Данные и выпуск

Номер/дата договора хранятся в существующем JSON objectDetails как basisContractNumber
и basisContractDate. Эти значения также включены в экспорт; номер участвует в поиске.
Сохраняются серверная проверка даты, права, версии и журнал событий.
Новых миграций и зависимостей нет. Нужны обычные коммит, сборка и активация релиза.

Проверены TypeScript, компиляция 26 Vue-компонентов, реальные компоненты в DOM:
переключение вкладок, клавиатура, сохранение полей, открытие реактивной записи без
DataCloneError, сохранение скрытых значений, действия компактной карточки и отсутствие
изменений формы обычных задач. Интеграционные API-тесты с Prisma проверили сохранение
новых реквизитов, недопустимые даты, права доступа, версии и журнал.
Полная production-сборка Nuxt и визуальная проверка в браузере целевого сервера
в этой среде не выполнялись.
