# УПТС — общая информация по объекту

Обновление Space-UPTS-object-general-20261105 устанавливается поверх
Space-UPTS-object-cards-tabs-20261105.

Над вкладками создания и редактирования объекта находится общий блок из шести полей:
номер договора, дата начала работ, дата окончания работ, куратор, кадастровый инженер,
количество этапов. На широком экране — три колонки, на узком — две или одна.
Оформление использует общие цвета светлой/тёмной темы. Блок доступен при любой вкладке.
Номер договора перенесён из характеристик без дублирования и потери значения.
Дата договора во вкладке характеристик сохранена: это отдельный реквизит.

Куратор и инженер выбираются из /api/upts/people (активные сотрудники УПТС).
При ошибке загрузки есть повтор; сохранённые назначения не стираются. Если сотрудник
выбыл из списка, прежнее назначение показано отдельной строкой. Сервер проверяет
новые назначения, неизменённые прежние допускает. Эти роли не изменяют права доступа
и не назначают автоматически исполнителей работ.

Дата начала хранится в objectDetails.workStartDate, количество этапов — в
objectDetails.stageCount. Номер договора и роли используют прежние поля JSON.
Дата окончания использует существующий dueDate объекта и отображается как его срок.
Новые поля необязательны; очистка сохраняет null. Количество этапов — положительное
целое число. Этапы и работы автоматически не создаются. Дата окончания не может
предшествовать началу. Сервер проверяет это также при запросе старого клиента без
objectDetails, используя сохранённую дату начала. Новые значения включены в Excel.
Права доступа, версии и аудит изменений остаются в существующем механизме сохранения.

Миграции и новые зависимости не нужны. Проверены TypeScript клиента/сервера,
компиляция Vue, DOM-проверки общего блока, ролей, дат и переключения вкладок,
интеграционные API-тесты с Prisma (сохранение, даты, количество этапов, роли,
версии, права и аудит). Полная production-сборка и визуальная проверка в браузере
целевого сервера в этой среде не выполнялись.
