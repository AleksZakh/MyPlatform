# УПТС: карточки работ и видимость договоров — 05.11.2026

Обновление поверх Space-UPTS-contracts-library-20261103-v2. Последующие изменения лаборатории не заменяются.

## Интерфейс

- Договору при создании назначается сохраняемый цвет. Полный круг оттенков, насыщенность HSL 50%, светлота 50%. Работы используют цвет договора в канбане, таблице, плане и календаре. Цвет обозначается полосой/акцентом; название остаётся основным идентификатором. Старые договоры получают устойчивый цвет отображения по ID без массовой перезаписи.
- В шапке работы — крупное название, ниже номер и название договора. В форме УПТС остаётся один выбор договора вместо одновременных полей «Проект» и «Договор УПТС». Общие задачи Space сохраняют свой выбор проекта.
- Убрано принудительное светлое оформление панели работы. Используется действующая тема Space, включая тёмную палитру диагностов и режим высокой контрастности.
- Уменьшены отступы и размер чисел статистических карточек УПТС.
- Для стандартных модальных окон, боковых карточек, нативных dialog и SweetAlert задана общая голубая тень с нулевым смещением по обеим осям.

## Видимость

| Выбор | Кто видит договор |
| --- | --- |
| Только мне | Владелец |
| Группе сотрудников | Владелец и выбранные сотрудники УПТС, добавленные в команду |
| Всем сотрудникам управления (по умолчанию) | Активные сотрудники подразделения и групп УПТС, владелец и команда |
| Всем | Все пользователи, допущенные в УПТС, в том числе системные администраторы |

По согласованному уточнению «Всем» не открывает раздел посторонним отделам. Право просмотра не означает право изменения: сохраняются роли владельца, руководителя, исполнителя и наблюдателя. Для группового варианта при создании можно выбрать сотрудников, затем менять состав через «Команда». Существующие договоры не переводятся в общие автоматически.

Новый договор создаёт отдельную область Space и папку в существующем хранилище. Настройки доступа этой области поддерживают новые варианты видимости. Договоры, ранее помещённые в одну общую область, по-прежнему имеют общую команду/права; изменение настроек доступа такой области относится ко всем её договорам.

## Исполнители

Полный список для руководителя договора объединяет активные учётные записи подразделения УПТС, прямых участников групп Space УПТС и участников связанных/одноимённых активных групп AD. Учитываются вложенные членства AD. Руководство не исключается по предположению о должности. Действующая команда сохраняется в выборе; поиск учитывает имя и логин. При сбое AD выводится ошибка, неполный список не выдаётся за полный.

Владелец/руководитель может назначить активного сотрудника УПТС вне команды. В той же транзакции сотрудник добавляется в команду с ролью исполнителя; это даёт доступ ко всему договору и отражается в журнале. Форма заранее поясняет это последствие. Для «Только мне» сначала требуется изменить видимость. Роль уже назначенного наблюдателя/куратора автоматически не повышается. Обычный исполнитель может назначать из существующей команды в пределах прежних прав.

Потеря допуска в УПТС блокирует доступ, даже если роль в договоре сохранилась. Недопущенные пользователи не получают работы или файлы через общие API Space.

## База данных

Миграция `20261105090000_upts_contract_visibility_color` добавляет nullable-цвет договора и расширяет допустимые scope общих проектов значениями `UPTS_DEPARTMENT` и `UPTS_ALL`. Не удаляет данные, файлы или участников. Требуется применить миграцию и сгенерировать Prisma Client перед активацией нового кода. Новых зависимостей приложения нет.
