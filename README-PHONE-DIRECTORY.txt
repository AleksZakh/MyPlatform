Space — телефонный справочник и загрузка сотрудников УПТС, 30.10.2026

Установка поверх текущего проекта с предыдущими обновлениями УПТС и тёмной темы:
1. Сохраните резервные копии заменяемых файлов.
2. Распакуйте архив в корень проекта Space, рядом с package.json.
3. Выполните npm run build и перезапустите Space.
4. Обновите страницу браузера.
Миграции БД и новые зависимости не нужны.

Изменения:
- Пункт «Сотрудники» в шапке заменён на «Телефонный справочник» и перенесён после «Библиотеки».
- Существующий адрес /ad/browser сохранён. Обновлено название страницы и хлебных крошек.
- Контакты загружаются автоматически при открытии. Общий справочник показывает сотрудников компании независимо от исходного раздела.
- Внутри УПТС пункт меню, ссылка из обзора и заголовок раздела переименованы в «Загрузка сотрудников». Его фильтры, права и расчёт показателей не изменены.
- Справочник читает сохранённый кэш АД через новый /api/contacts. Прямой запрос к АД при каждом открытии не выполняется, старого ограничения в 500 записей нет.
- Показываются ФИО, телефон, электронная почта, подразделение и должность. Отключённые учётные записи не включаются. Технические атрибуты АД не возвращаются этим endpoint.
- Доступны поиск, фильтр подразделения, сортировка и постраничный просмотр по 25 записей. Обновление списка сохраняет введённые фильтры.
- «Обновить» повторно читает текущий сохранённый каталог. Обновление самого кэша АД остаётся в существующем механизме портала. Внизу показано время обновления данных.
- При отсутствии кэша или ошибке показывается сообщение и кнопка повторной попытки. При наличии старого кэша он доступен вместе с датой обновления.
- Технические кнопки просмотра групп АД убраны со страницы телефонного справочника. Административные разделы групп и прежние API АД не изменены.

Проверено:
- Целевая проверка Vue/TypeScript с тестовыми декларациями среды Nuxt/Nitro.
- Endpoint на тестовом кэше: отсутствие/пустой/старый кэш, 601 контакт без обрезки, исключение отключённых записей, только поля контакта в ответе.
- Браузер: автоматическая загрузка, поиск, фильтр подразделения, сортировка, пагинация, повтор после ошибки, пустой список, тёмная тема, экран 390 px без переполнения страницы.
- Браузерная проверка существующих сценариев УПТС после переименования меню.
Полная сборка Nuxt с рабочей БД/АД в этой среде не выполнялась.
