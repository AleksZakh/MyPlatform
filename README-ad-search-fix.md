# Исправление поиска сотрудников AD и ширины панели чата

Устанавливать поверх Space-chat-invitations-20261012 (релиз 20261012T095517Z-92d3564e82dd).

Что исправлено:
- Поиск объединяет пользователей Space и сотрудников из существующего кэша AD. Без поискового запроса список контактов по-прежнему показывает только активированные записи Space.
- Сотрудники, ещё не добавленные в Space, доступны для приглашения. При выборе контакта запись не создаётся и письмо не отправляется.
- После подтверждения: живая проверка профиля AD, objectGUID (при отсутствии в старом кэше — получение из AD по логину), статуса и корпоративной почты; создание ожидающей активации записи; отправка приглашения.
- Если отправка письма не удалась, созданная запись остаётся ожидающей, не активной. Ограничения повторной отправки и правила активации из предыдущего обновления сохранены.
- Повторная проверка на сервере запрещает подмену идентичности, восстановление заблокированной записи, конфликт логина/email и обход блокировки через результат из кэша. Поиск объединяется до постраничного разбиения.
- Если кэш недоступен, интерфейс сообщает, что поиск ограничен пользователями Space. Если отсутствует конкретный сотрудник, обновите кэш AD штатной административной функцией. Каталог не опрашивается целиком на каждое нажатие клавиши.
- На обычном экране левая панель фиксирована на 280px; ширина модального окна задана явно. На узких экранах панель адаптируется, вкладки не переносятся, при нехватке места прокручиваются горизонтально. Пустой результат не меняет ширину столбцов.

Установка:
1. Распакуйте файлы в исходный проект на компьютере разработки, сохранив структуру. Закоммитьте и доставьте коммит на сервер. При расхождении веток сохраните серверные исправления через merge; node_modules не добавлять в Git.
2. На сервере в /var/www/html/MyPlatform выполните space-release prepare и дождитесь READY.
3. space-release db-status RELEASE_ID — новых миграций в этом исправлении нет. Ранее установленная 20261012120000_domain_chat_invitations должна быть применена.
4. space-release activate RELEASE_ID --db-compatible — короткий перерыв при переключении.
5. space-release status, затем обновите страницу в браузере.

Проверка: найдите сотрудника, которого ещё нет в Space, отправьте приглашение, проверьте ожидающую запись и затем вход через AD. Введите заведомо отсутствующее имя: панель не должна сжиматься, вкладки должны остаться на одной строке.

Проверено локально: vue-tsc -b; клиентский тест приглашений и сообщений; тест объединения контактов, исключения заблокированных и повторных записей, отсутствующего GUID в кэше, пустого результата и пагинации; интеграционный тест создания ожидающей записи, отправки и активации на изолированной PostgreSQL-совместимой БД PGlite со заглушками AD/SMTP. Реальные корпоративные AD/SMTP и визуальная проверка в браузере пользователя недоступны; их нужно проверить после развёртывания. Полная production-сборка выполняется командой prepare.
