# Space — телефонный справочник, этап 3

## Настройки AD

В серверном .env укажите полные DN-контейнеров пользователей:

```dotenv
AD_PHONEBOOK_GK_USERS_DN=""
AD_PHONEBOOK_UK_USERS_DN=""
AD_PHONEBOOK_ROADS_USERS_DN=""
```

Соответствие вкладок: group = ГК Автодор, management = УК Автодор, roads = Автодор-Платные дороги.
Инжиниринг продолжает использовать существующий кэш AD, заполняемый через AD_DOMAIN_USERS.

Переменные AD_URL, AD_USERNAME и AD_PASSWORD остаются общими для всех контейнеров.
Указывайте полные DN со всеми OU/DC. Контейнеры должны находиться на доступном LDAP-сервере.
Данные новых вкладок кэшируются на час после первого успешного обращения; при ошибке LDAP сохраняется предыдущий кэш.

## Установка

1. Создайте резервную копию проекта и PostgreSQL.
2. Распакуйте архив поверх проекта, сохраняя структуру каталогов.
3. Задайте переменные в .env.
4. Выполните:

```bash
npm ci
npx prisma migrate deploy
npx prisma generate
npm run build
pm2 restart <имя-процесса>
```

Миграция создаёт таблицу phone_directory_details и не меняет существующие данные.
Используйте архив как полное обновление для предыдущих этапов, а не только как дополнение.

## Интерфейс

- Фон панелей и таблицы осветлён, но остаётся отличным от белого.
- Заголовок «Информация о выбранном сотруднике» убран.
- Аббревиатуры отделов формируются из начальных букв значимых слов.
- Известные исключения: Административно-хозяйственный отдел → АХО;
  Отдел информационно-технического обеспечения → ОИНТО.
- Все вкладки используют общие поиск, фильтры, выбор контактов и локальные поля.

## Проверка

- Откройте вкладку ГК, затем УК и Платные дороги; проверьте количество сотрудников и имена.
- Убедитесь, что в новой вкладке нет сотрудников из другого OU (если OU не вложены).
- Проверьте редактирование своей карточки и запрет редактирования чужой для обычного пользователя.
- Проверьте после обновления страницы сохранение города/адреса/комнаты/мобильного телефона.

ВНИМАНИЕ: AD_BASE_DN присутствует в примере пользовательского .env, но в переданном исходнике
Nuxt настройка groupsBaseDN жёстко задана. В этом обновлении её не меняли, чтобы не затронуть
действующие проверки групп/прав.
