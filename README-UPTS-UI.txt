УПТС — оформление и навигация

Установить поверх ранее установленного Space-UPTS-pilot-20261030.zip.
Распаковать 5 файлов с сохранением структуры в корень проекта Space.

Изменения:
1. УПТС добавлен в общую сетку через существующий DepartmentCard; отдельный широкий баннер удалён.
2. В общем каталоге навигации добавлен пункт УПТС для меню «Отделы».
3. Фон боковой панели УПТС — серый градиент; подписи нейтральные светло-серые, активный пункт синий.

Численность УПТС и руководитель пока неизвестны: «Состав уточняется» и «Не указан». Их можно заполнить в server/api/departments.get.ts. Данные других отделов сохранены.

Миграция БД, генерация Prisma Client и установка зависимостей не требуются.
Для рабочего приложения: npm run build, затем обычный перезапуск Space.
В режиме разработки перезапустите dev-сервер при необходимости.

Проверены компиляция Vue-компонентов, отсутствие дублирующей плитки и пункта меню, отображение серого градиента в браузере.
