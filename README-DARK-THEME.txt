Space — единая тёмная тема и руководитель УПТС, 30.10.2026

Установка поверх текущего Space с установленными обновлениями УПТС:
1. Сохраните копии заменяемых файлов.
2. Распакуйте архив в корень проекта (рядом с package.json), согласившись на замену.
3. Выполните npm run build и перезапустите Space.
4. Обновите страницу браузера.
Миграции БД, Prisma generate и новые зависимости не требуются.

Изменения:
- Общая тёмная палитра использует цвета диагностики: фон #263542, панели #344757, поля и hover карточек #20313f, текст #edf3f8.
- Подключён единый файл app/assets/css/portal-dark.css. Он согласует общие Nuxt UI переменные и старые локальные темы лаборатории, задач/УПТС, библиотеки и административных панелей.
- Устранён белый hover карточек главной страницы в тёмной теме. Светлая тема, режим повышенной контрастности и печать сохраняют прежнее оформление.
- Руководитель УПТС: Евгений Миронычев. При однозначном совпадении имени и фамилии в сохранённом кэше АД выводится полное имя из кэша, в том числе отчество. Порядок имени/фамилии, регистр и е/ё учитываются.
- Отключённые учётные записи исключены. При отсутствии кэша/совпадения или нескольких тёзках используется указанное имя. Прямых LDAP-запросов при открытии главной нет.
- Это отображение подтверждённого назначения, а не автоматическое определение нового руководителя по должности. В текущей модели кэша отсутствуют связи руководителя подразделения. Для автоматического обновления самого назначения нужна явная связь отдела с учётной записью руководителя.
- Численность УПТС не вычисляется по предположительным названиям department.
- Названия меню и поведение телефонного справочника в этот архив не входят: варианты предложены для обсуждения.
