# Space — сокращение отделов, версия 2

Точечное обновление поверх последнего релиза телефонного справочника.

Изменяется только `shared/utils/phone-directory-acronym.ts`. В архиве также находится тест `tests/phone-directory-acronym.test.ts`.

## Правило

- Подсчитываются слова, разделённые пробелами, табуляцией и другими пробельными символами.
- Союз `и` (в любом регистре) не учитывается при подсчёте значимых слов.
- Если значимых слов не более 8, выводится аббревиатура. Союз `и` остаётся строчным внутри неё.
- В кратких названиях части, разделённые запятыми, образуют отдельные группы аббревиатур, соединённые пробелами.
- Если значимых слов больше 8, выводятся первые 4 значимых слова без аббревиатуры; встретившийся между ними союз `и` сохраняется и пишется строчными буквами.
- Полное название отдела в правой карточке не меняется.

Примеры:

| Исходное название | В таблице |
| --- | --- |
| Отдел кадров и делопроизводства | ОКиД |
| Учебный центр, отдел образовательных программ | УЦ ООП |
| один два три четыре пять шесть семь восемь | ОДТЧПШСВ |
| один два три четыре пять шесть семь восемь девять | один два три четыре |
| Отдел развития и поддержки управления контроля качества проектов компании региона | Отдел развития и поддержки управления |

## Проверка

```bash
node --import tsx --test tests/phone-directory-acronym.test.ts
npm run build
```

После сборки разверните новый релиз стандартным способом. Миграции БД и новые переменные окружения не требуются.
