# Space — исправление аббревиатур отделов

Это точечное обновление поверх этапа 3. Распакуйте архив в корень проекта, сохранив пути файлов.

Изменены:
- `app/pages/ad/browser.vue`
- `shared/utils/phone-directory-acronym.ts` (новый файл)

В каждой строке таблицы значение отдела из AD переводится в аббревиатуру по начальным буквам слов. Запятые разделяют части, аббревиатуры соединяются пробелом. Полное название остаётся в карточке сотрудника.

Пример: `Учебный центр, отдел образовательных программ` → `УЦ ООП`.

Проверка:

```bash
node --import tsx --test tests/phone-directory-acronym.test.ts
npm run build
pm2 restart <имя-процесса>
```

Новые переменные окружения и миграции для этого исправления не нужны.
