Space / УПТС — компактная верхняя панель, 30.10.2026

Установка поверх установленной пробной версии УПТС с предыдущим исправлением дизайна:
1. Сохраните резервную копию двух заменяемых файлов.
2. Распакуйте содержимое архива в корень проекта Space (рядом с package.json), согласившись на замену файлов.
3. Выполните npm run build и перезапустите Space обычным для вашего сервера способом.
4. Обновите страницу в браузере.
