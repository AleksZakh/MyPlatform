# Профиль и персональные настройки Space

Обновление поверх версии с групповыми чатами от 12.10.2026.
Заменить файлы архива по соответствующим путям в корне проекта.
Страница: app/pages/profile/index.vue (существующий пункт меню «Профиль»).

Возможности:
- Светлая/тёмная/системная тема, повышенный контраст (светлая палитра), три размера текста, две плотности.
- Применение настроек кнопкой «Применить», восстановление исходных значений.
- Настройки обычных, успешных и чат-уведомлений, отдельный звук чата.
- Предупреждения и ошибки не отключаются. Дубли обычных тостов объединяются в пределах 3 секунд.
- Порядок и видимость колонок лабораторного реестра хранятся в профиле; новые колонки добавляются в общий порядок, видимость определяется настройкой.
- Кнопка переноса старого localStorage tableSettings в профиль. Перенос явный: прежнее значение не было привязано к учётной записи, поэтому автоматически присваивать его пользователю нельзя.
- Сброс таблицы с подтверждением. Сохранение после перетаскивания колонки; при ошибке порядок возвращается к сохранённому и показывается сообщение.
- Разворачивание окон создания/редактирования/просмотра реестра в область браузера; настройка начального размера в профиле.
- Более заметные границы полей и всплывающих списков, адаптивные колонки форм.

Хранение: новая таблица user_preferences, один объект на пользователя. API определяет пользователя только из сессии и проверяет активность. Клиент не может передать чужой userId. Изменения секций сериализуются транзакцией. app_users.updatedAt не меняется, приглашения и активация не затрагиваются. localStorage содержит только настройки с ключом ID пользователя; сервер — основной источник. Права и состав учётной записи в этих настройках не хранятся.

На компьютере разработки:
1. Убедиться, что DATABASE_URL в локальном окружении указывает на тестовую БД.
2. Применить миграции: npx prisma migrate deploy
3. Сгенерировать клиент: npx prisma generate
4. Перезапустить dev-процессы.

На сервере:
1. Сделать резервную копию БД.
2. Получить закоммиченные изменения в исходном каталоге.
3. space-release prepare
4. space-release db-status RELEASE_ID
5. space-release migrate RELEASE_ID
6. space-release activate RELEASE_ID --db-compatible
7. space-release status
8. Проверить HTTP health на 3000 и WebSocket health на 5050, вход и страницу /profile.

Новая миграция: 20261012170000_user_preferences. Только добавляет таблицу с внешним ключом, старые данные не удаляет. Ограничения отката группового чата остаются в силе.

Проверка пользователем:
- Изменить контраст/шрифт/плотность, нажать «Применить», перезагрузить страницу; открыть под той же учёткой на другом компьютере.
- Переставить дату отбора, перезагрузить; скрыть/вернуть колонку.
- Переключить учётную запись: настройки должны быть независимыми.
- Отключить успех/информацию: ошибки и предупреждения остаются.
- Проверить новое входящее сообщение при закрытом чате, отсутствие повторного тоста при опросе; собственные сообщения и первоначальная история не уведомляют.
- Для звука сначала взаимодействовать со страницей; политика браузера может запрещать звук до нажатия. Это уведомления внутри Space, не системные push при закрытом браузере.
- Проверить формы с крупным текстом, на узком экране и при масштабе браузера 200%.

Локальные автоматические проверки: миграция и API на изолированной PostgreSQL-совместимой БД, валидация, разделение учёток, защита ошибок от отключения, логика новых сообщений, регрессия личного/группового чата, проверка типов Nuxt/Vue.
Полная production-сборка и проверка оформления на корпоративных рабочих местах выполняются при развёртывании. Изменение палитры не означает сертифицированного соответствия WCAG для всего приложения; таблицы и сторонние компоненты требуют визуальной проверки пользователями.

Отложенные задачи не изменены: просмотр PDF в Яндекс-браузере, диагностика задержек отправки, локальный HTTPS, перенос рабочей БД на корпоративный сервер.
