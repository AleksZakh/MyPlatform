# Редактирование и удаление сообщений

Пакет поверх групповых чатов и персональных настроек от 12.10.2026. Содержит последние исправления отступов Launcher.vue. GroupPanel.vue не заменяется.

Действия доступны по кнопке «⋯» у своего сообщения. Время изменения не ограничено. Редактирование сохраняет исходную дату сообщения и добавляет отметку «изменено». Удаление требует подтверждения и заменяет содержимое на «Сообщение удалено» для всех участников. В архивных группах действия отключены; исключённые участники не могут менять сообщения. Владелец и администратор группы не могут менять чужие сообщения.

Предыдущий текст, автор действия, действие, время и предыдущая версия сохраняются в chat_message_revisions. История не возвращается через API чата и недоступна обычным участникам. Текст удалённого сообщения очищается в chat_messages, но сохраняется в истории изменений БД. Это мягкое удаление, а не уничтожение данных. Обычного восстановления удалённых сообщений нет.

Операции выполняются в одной транзакции с блокировкой диалога. Версия сообщения предотвращает перезапись из устаревшего окна. Повторный запрос с уже применённым текстом или повторное удаление не создают дубликатов истории. При конфликте черновик редактирования сохраняется: отмените редактирование и откройте актуальное сообщение заново. Лимит частоты — 60 фактических изменений в минуту на автора, не ограничение возраста сообщения.

Синхронизация: существующее WebSocket-событие вызывает обновление; отдельный курсор revision доставляет изменения старых сообщений независимо от ID новых. При недоступности WebSocket сохраняется опрос раз в 15 секунд. Изменения не вызывают уведомления о новом сообщении. Удалённые строки сохраняют место в истории и не считаются непрочитанным содержимым. Предпросмотр последнего удалённого сообщения в списке диалогов показывает заглушку.

## Установка

1. Распаковать файлы в корень проекта на компьютере разработки, сохранить структуру каталогов.
2. Для тестовой БД: npx prisma migrate deploy, затем npx prisma generate. Перезапустить Nuxt.
3. Закоммитить изменения, получить их на сервере.
4. Сделать резервную копию БД.
5. space-release prepare
6. space-release db-status RELEASE_ID
7. space-release migrate RELEASE_ID
8. space-release activate RELEASE_ID --db-compatible
9. space-release status
10. Обновить страницы браузеров у тестирующих пользователей.

Миграция: 20261012195000_chat_message_actions. Добавляет поля версии/дат в сообщения, счётчик версии диалога и таблицу истории. Физического удаления старых сообщений нет. WebSocket-сервер и секреты не меняются.

Совместимость: после начала использования удаления старый интерфейс может показывать пустое содержимое вместо заглушки; он не умеет синхронизировать правки. Не откатывайте интерфейс на старую версию без учёта этого ограничения. Прежние ограничения отката групповых чатов также действуют.

## Проверка

- Личный и групповой диалог: отправить, изменить, удалить своё сообщение.
- У собеседника: правка и заглушка появляются на прежнем месте; чужих действий нет.
- Сохранён исходный timestamp, появляется «изменено».
- После перезагрузки удалённый текст не возвращается; API не отдаёт предыдущие версии.
- Изменить одно сообщение в двух вкладках: второе сохранение устаревшей версии отклоняется.
- Архивировать группу: кнопки исчезают, прямой запрос изменения отклоняется.
- Проверить старые загруженные сообщения и догрузку истории.

Автоматические проверки: транзакции и миграция на изолированной PostgreSQL-совместимой БД, авторство и членство, архив/блокировка, отсутствие ограничения возраста, конфликты, повторные запросы, сохранение истории, пагинация изменений; клиентские тесты редактирования и синхронизации; проверка типов Vue/Nuxt. Проверку взаимодействия двух реальных браузеров выполнить в тестовой среде.
