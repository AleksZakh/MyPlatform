# Space — полные названия отделов в телефонном справочнике

Небольшое обновление отображения колонки «Отдел» во всех четырёх организациях.

## Что изменено

- В каждой строке таблицы отображается **полное** название отдела из AD; аббревиатуры больше не используются.
- Шрифт названия отдела — 11 px, межстрочный интервал — 1.3.
- Текст свободно переносится на несколько строк, включая длинные слова. Усечение многоточием и скрытие строк не применяются.
- Таблица использует фиксированное распределение ширины столбцов. Колонке «Отдел» отдано 27% ширины, минимальная общая ширина таблицы — 880 px. При узком экране горизонтальная прокрутка остаётся **внутри таблицы**, не расширяя страницу.
- Правая карточка сотрудника и сведения AD не меняются. Поиск, фильтрация, сортировка и редактирование локальных полей работают как прежде.

## Установка

Распакуйте архив поверх актуальных исходников Space, сохранив относительные пути, затем выполните обычную сборку и публикацию релиза.

Файл интерфейса: `app/pages/ad/browser.vue`. Дополнительно включён тест `tests/phone-directory-acronym.test.ts`, в котором проверяется отсутствие сокращения в таблице. Старый вспомогательный алгоритм сохранён в проекте, но больше не используется на этой странице.

Новых зависимостей, миграций Prisma и переменных `.env` нет.

## Проверка

`node --import tsx --test tests/phone-directory-acronym.test.ts tests/phone-directory-contact.test.ts tests/phone-directory-avatars.test.ts`

Если у какого-то отдела очень длинное название, его ячейка может занимать больше строк по высоте: это необходимо, чтобы показать название полностью без обрезания.
