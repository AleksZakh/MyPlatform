Space · ОДИС · Отчёт «Ход работ»
Обновление от 27.11.2026 поверх Space-ODIS-progress-grid

Установка

Если архив лежит в /tmp на сервере, выполните

  unzip /tmp/Space-ODIS-progress-display.zip -d /tmp/odis-progress-display
  cd /var/www/html/MyPlatform
  git apply --check /tmp/odis-progress-display/Space-ODIS-progress-display.patch
  git apply /tmp/odis-progress-display/Space-ODIS-progress-display.patch

Затем включите изменения в штатную сборку и разверните релиз Space. Обновление использует действующую схему БД и ранее импортированные данные. Чтобы увидеть изменения, сформируйте «Ход работ» заново.

Что проверить

1. В семи столбцах от «Полевые работы» до «АИС видео» указаны только исполнители. Для работы берётся фактический исполнитель, при пустом поле — плановый. Для командировки используются участники. Несколько сотрудников выводятся отдельными строками. Если один сотрудник выполнял несколько работ в этой ячейке, его ФИО показывается один раз. При пустом составе в браузере отображается прочерк, в Excel ячейка пустая. Результаты, примечания и отдельные назначения доступны в редакторе ячейки.
2. Код ИССО занимает одну строку. В Excel колонка расширяется по самому длинному коду на листе. Код хранится в ячейке как текст для сохранения ведущих нулей.
3. Кнопка «Сохранить в Excel» выдаёт файл вида «Ход работ_ДСиР-2020-1164_27.11.2026.xlsx». При повторном экспорте в тот же день имя скачиваемого файла остаётся таким же. В папке Reports хранилища ОДИС совпадающим именам добавляется номер копии в скобках, например « (2)». Каждый экспорт сохраняет собственную копию, в том числе при одновременных запросах.
