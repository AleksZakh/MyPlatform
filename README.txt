Настраиваемый лимит выгрузки реестра

1. Скопируйте файлы архива в проект с сохранением структуры.
2. Добавьте модель из prisma/lab-export-settings-model.txt в вашу актуальную prisma/schema.prisma один раз. Не заменяйте всю схему.
3. Выполните в проекте:
   npx prisma migrate deploy
   npx prisma generate
   npm run build
4. Перезапустите приложение и отдельный worker экспорта, если он запускается отдельно.

В центре администрирования появилась плитка «Настройки экспорта» (/admin/export-settings). Доступ и сохранение разрешены системным администраторам из существующего NUXT_ADMIN_LOGINS. Изменение сохраняется в БД и журнале событий.

Начальное значение — 500 записей, диапазон настройки — 1–10000. Учитывается только «Настройка фильтра», не быстрый поиск, выделение и текущая страница. Ровно лимит разрешён. Выборка сверх лимита полностью блокируется, не обрезается. Число документов не меняет количество записей.

Окно экспорта показывает число записей и лимит. Пока проверка не завершена, при её ошибке и при превышении кнопка недоступна. Число и лимит обновляются вместе с опросом состояния выгрузок.

Сервер повторяет проверку до создания задания. Worker получает не более limit+1 записей и проверяет превышение до подготовки файлов. Проверки выполняются также при подтверждении и перед сборкой ZIP, включая задания, созданные до обновления. Уже готовые архивы остаются доступными. При снижении лимита незавершённое задание сверх нового ограничения не будет сформировано.

Проверено: vue-tsc; генерация Prisma Client; граница 500/501; допустимые и недопустимые настройки; изменение лимита; отказ при недоступной БД. Миграция и ZIP на реальной серверной БД не запускались.

Компонент ExportRecordsModal.vue и сервисы worker/store взяты из ранее присланного полного проекта; endpoint index.post.ts — из актуального exports.zip.
