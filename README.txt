ОДИС · Карточка сооружения и история изменений
27.11.2026

Пакет устанавливается поверх обновления Space-ODIS-roads-categories.

Установка
Если архив скопирован в /tmp, распакуйте и примените патч в исходном дереве проекта.

  unzip /tmp/Space-ODIS-structure-card.zip -d /tmp/odis-structure-card
  cd /var/www/html/MyPlatform
  git apply --check /tmp/odis-structure-card/Space-ODIS-structure-card.patch
  git apply /tmp/odis-structure-card/Space-ODIS-structure-card.patch

Включите изменения и новую миграцию в штатный релиз Space. До запуска новой версии необходима миграция 20261127173000_odis_structure_card_history и генерация клиента Prisma для сборки. Если штатный сценарий развёртывания уже выполняет эти шаги, достаточно запустить его. Для ручного выполнения из дерева с применённым патчем и установленными зависимостями:

  node --env-file=/etc/space/space.env ./node_modules/prisma/build/index.js migrate deploy
  node --env-file=/etc/space/space.env ./node_modules/prisma/build/index.js generate

Затем выполните штатную сборку и развёртывание Space. При первом применении миграция на время переноса журнала блокирует запись в таблицу сооружений. Отдельный импорт Excel или запуск скрипта заполнения истории не требуется.

Проверка в интерфейсе
1. Договор → Перечень сооружений. Один щелчок выбирает сооружение и показывает работы. Двойной щелчок по строке или кнопка «Карточка сооружения» открывает карточку выбранного объекта. Чекбокс и переключатель этапа работают отдельно.
2. Вкладки «Основное», «Характеристики», «Работы и примечания» доступны из договора и из справочника. Нажмите «Редактировать», измените данные и сохраните. Карточка остаётся открытой, строка сооружения обновляется. Право изменения выдаётся на справочник сооружений. Уже присвоенный код ИССО и сведения о договорах и исполнителях из старой базы доступны для чтения. Если код ещё не присвоен, его можно внести.
3. Откройте «История изменений». Новые изменения содержат автора, дату, время и прежнее и новое значения изменённых полей. Имя файла показывается, если оно было записано при импорте. История загружается при открытии вкладки, порциями по 25 событий. Для выведенного из эксплуатации объекта, оставшегося в договоре, доступен просмотр.
4. В справочнике «Сооружения» рядом с километражом показана дорога. Примечание видно на вкладке «Основное» под перечнем договоров.

Что будет видно для ранее внесённых объектов
Миграция переносит сохранённые события аудита и сведения о создании, импорте и последнем изменении карточек. Если в старой записи есть только дата, автор или источник, выводятся доступные сведения. Последующие изменения фиксируются триггером в той же транзакции, что и изменение сооружения. Автор берётся из данных записи; для штатного скрипта очистки автодорог отображается «Обновление ОДИС».
