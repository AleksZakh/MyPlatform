# Space — фото сотрудников в телефонном справочнике

Это обновление продолжает текущую реализацию телефонного справочника.

## Изменения

- Карточка сотрудника показывает его фото, загруженное в личном кабинете Space.
- Если фото нет или оно не загрузилось, остаётся иконка `streamline-freehand-color:face-id-male-1`.
- Фото связываются с доменными учётными записями Space по `objectGUID` AD; для старой записи без GUID допускается совпадение логина. Контактам AD без учётной записи в Space остаётся иконка.
- Для фото добавлен закрытый авторизацией URL `/api/contacts/avatars/:userId`. Изображение запрашивается только при открытии карточки, в списке передаются только версия и URL.
- Четвёртая вкладка названа «Автодор-Платные дороги и другие общества группы компаний». Её высота адаптирована под перенос строк, в том числе в узкой панели.

## Установка

Распакуйте архив поверх актуальной исходной версии Space с сохранением путей, затем выполните обычную сборку и публикацию релиза. Все пути внутри архива относительны корню проекта.

Миграции Prisma, дополнительные переменные `.env` и новые зависимости не требуются.

После публикации проверьте сотрудника с аватаром, сотрудника без аватара и контакт AD без учётной записи Space. Если фото изменилось в личном кабинете, нажмите кнопку обновления телефонного справочника либо откройте его заново.
