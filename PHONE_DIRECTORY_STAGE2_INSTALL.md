# Space — телефонный справочник, этап 2

## Изменения

- Оформление панелей, таблицы, вкладок и прокрутки внутри рабочей области.
- Сокращения отделов в таблице, полные названия в карточке.
- Поиск по ФИО, должности, отделу, обоим телефонам, почте, городу, адресу и комнате.
- Редактируемые локальные поля: город, адрес, комната, мобильный телефон.
- Доступ: своя карточка или право UPDATE на ресурс admin.users (включая системных администраторов).
- Поля Active Directory нельзя редактировать через API справочника.

## Установка на Ubuntu

1. Сохраните резервную копию приложения и базы PostgreSQL.
2. Распакуйте архив в корень проекта Space, сохранив структуру каталогов.
3. Проверьте переменную DATABASE_URL в окружении приложения.
4. Выполните:

```bash
npm ci
npx prisma migrate deploy
npx prisma generate
npm run build
pm2 restart <имя-процесса>
```

Миграция создаёт только новую таблицу `phone_directory_details`. Существующие данные AD и таблицы сотрудников не изменяются.

## Проверка

1. Авторизуйтесь обычным сотрудником, откройте свою карточку и сохраните город.
2. Перезагрузите страницу: город должен сохраниться.
3. В чужой карточке кнопка редактирования отсутствует; прямой PATCH возвращает 403.
4. Вход под администратором должен позволять редактировать любую карточку.
5. Синхронизация AD не должна стирать дополнительные поля.

Примечание: для пользователей без objectGUID сопоставление выполняется по нормализованному логину AD. Сокращения отделов формируются автоматически, кроме явно известных АХО и УО. Для точных корпоративных аббревиатур понадобится отдельная карта соответствий.
