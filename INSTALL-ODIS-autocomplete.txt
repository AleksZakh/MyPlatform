ОДИС • Автозавершение запланированных работ

Установка поверх версии с формой «Добавление работ в план»

1. Распакуйте архив в корень MyPlatform с заменой файлов.
2. Если предыдущая версия автозавершения уже установлена и её миграция применена, достаточно выполнить npm run build и перейти к шагу 3.
   При первой установке автозавершения в корне проекта, с обычным для Space окружением подключения к БД, выполните последовательно:

   node scripts/install-odis-autocomplete-schema.mjs
   npx prisma migrate deploy
   npx prisma generate
   npm run build

3. Перезапустите процесс приложения Space в PM2 обычным способом.
   Обработчик дат запускается вместе с приложением. Отдельное задание cron не требуется.

Столбец «Автозавершение» относится к каждой строке перечня. Общий флажок переключает все работы перечня, кроме командировок, которые обрабатываются в собственном разделе. При добавлении новой строки флажок снят.

Сроки определяются по московской календарной дате. В день начала статус становится «Выполняется». С 00:00 следующего дня после планового окончания при включённом автозавершении записываются фактические даты планового периода и трудозатраты из библиотеки на момент назначения. При выключенном флажке незакрытая работа становится просроченной. Вся плановая дата окончания доступна для выполнения и ручного закрытия, в том числе у однодневных работ. Фактическое окончание при автозавершении равно плановой дате окончания. Для ранее назначенных работ автозавершение выключено.

Обновление дат выполняется пакетами при старте и затем примерно раз в минуту. После простоя сервер догоняет пропущенные даты. Чтобы увидеть изменения в уже открытом списке, нажмите «Обновить».
