ОДИС • Автозавершение запланированных работ

Установка поверх версии с формой «Добавление работ в план»

1. Распакуйте архив в корень MyPlatform с заменой файлов.
2. В корне проекта, с обычным для Space окружением подключения к БД, выполните последовательно:

   node scripts/install-odis-autocomplete-schema.mjs
   npx prisma migrate deploy
   npx prisma generate
   npm run build

3. Перезапустите процесс приложения Space в PM2 обычным способом.
   Обработчик дат запускается вместе с приложением. Отдельное задание cron не требуется.

Столбец «Автозавершение» относится к каждой строке перечня. Общий флажок переключает все работы перечня, кроме командировок, которые обрабатываются в собственном разделе. При добавлении новой строки флажок снят.

Сроки определяются по московской календарной дате. В день начала статус становится «Выполняется». В день окончания при включённом автозавершении записываются фактические даты планового периода и трудозатраты из библиотеки на момент назначения. При выключенном флажке незакрытая работа становится просроченной. Дата окончания входит в эту проверку с начала дня, поэтому однодневная работа в этот день сразу получает итоговый статус. Для ранее назначенных работ автозавершение выключено.

Обновление дат выполняется пакетами при старте и затем примерно раз в минуту. После простоя сервер догоняет пропущенные даты. Чтобы увидеть изменения в уже открытом списке, нажмите «Обновить».
